Task 4: Semantic and Non-Semantic Tags

Semantic Tags

These tags describe the meaning of their content.

  • <header> - Top section of a page
  • <nav> - Navigation links
  • <main> - Main content of the page
  • <section> - Thematic group of content
  • <article> - Self-contained content
  • <aside> - Side content
  • <footer> - Bottom section of a page
  • <mark> - Highlighted text

Non-Semantic Tags

These tags say nothing about their content.

  • <div> - Generic block container
  • <span> - Generic inline container
  • <b> - Bold text (visual only)
  • <i> - Italic text (visual only)
  • <u> - Underlined text
  • <br> - Line break
  • <hr> - Horizontal line
  • <small> - Smaller text
  • <sub> - Subscript
  • <sup> - Superscript
